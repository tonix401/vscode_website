CSS Inlining

The viewer resolves <link rel="stylesheet"> tags at render time and inlines the content as a <style> block — external stylesheets load inside the sandboxed iframe without any server.

In-App Navigation

Relative <a href> links navigate within the viewer. Clicks are intercepted via postMessage and routed to the correct file — no page reload, no new tab.

Typography

This page uses Space Grotesk — a geometric sans-serif loaded from Google Fonts. Code snippets fall back to JetBrains Mono to match the editor pane.
